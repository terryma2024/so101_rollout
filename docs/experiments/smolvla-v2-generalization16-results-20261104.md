# v2 新位置组合16条筛查结果

本次仅新位置组合16条；历史C2/C3全12条独立作为参考，不混入本次分母。采用同一v2 20k权重和hard异步20Hz/horizon50/prefetch10/maxrel30。结果来自侧面视频抽帧及重点补帧视觉复核，不是新增操作者人工验收。每个布局/指令仅重复2次，不能外推总体可靠率。

## 结果

目标色入碗9/16（56.3%），抓绿2/8，抓红7/8。稳定抓起的11条中颜色正确9/11（81.8%）；正确色抓起占全部试次9/16。未观察到稳定抓起5条（05、06、08、14、15），不可算选色正确；03、12均为绿色指令抓红并将红放进碗。

成功编号01、02、04、07、09、10、11、13、16。五条无稳定抓起的视频补看2.5、3.5、4.5、5.5、6.5、7.5、9、11、13、17、21秒及末帧；末态两块留桌面、碗空。部分出现改变尝试目标，不等于已抓起错误颜色。抽帧不能排除样本间短暂抓起或接触。

历史C2/C3为11/12（91.7%），抓绿5/6、抓红6/6，稳定抓起颜色正确11/11。本次与历史相差35.4个百分点，仅为描述性差异，无同期控制。

## 完整性及干扰

16/16执行及archive完整，无错误/丢帧，4943帧动作与parquet逐元素一致。132次实际语言输入token解码均符合计划，模型SHA及运行代码与历史v2相同。约19.97Hz，warm推理均值181.86ms，无队列饥饿，跳tick1。限幅12条集中05/06，每条6次；不能单凭共现认定失败原因。

preflight全部通过，光照/相机对齐数值与历史接近；初始wrist_roll均值较历史+3.56、夹爪−2.52（数据state标度，未认定物理单位）。存在初姿、摆放、局部阴影和噪声差异，因此不能将历史成功率差异完全归因于组合变化。

## 判断及后续建议

v2在本次新组合上尚未显示可靠泛化，主要弱项是绿色任务，既有错色也有未抓起。B2/B3互换后的绿色指令两次均抓红B2，而红色指令两次也成功抓红B2，支持把位置偏好作为待验证假设；不足以证明模型内部忽略语言。B1/C3远间距布局的绿色失败还表明问题并不限于先前C3/C2一对位置。

建议先复用现有视频观测做固定噪声、只替换红/绿指令的离线对照，观察选色与动作方向是否改变，再决定补采与训练。若补采，优先这三种绿色失败组合，并在相同物理布局下配对抓红示范；不只补绿色，避免新的颜色/位置相关性。保留本次16条为测试证据，不把失败rollout当专家示范。任何下一轮训练、补采数量及执行包均尚未启动。
