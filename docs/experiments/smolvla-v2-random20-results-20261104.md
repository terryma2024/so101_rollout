# SmolVLA v2 random20 离线视觉结果（2026-11-04）

20条中正确颜色最终留碗14/20（70%）；红色8/10，绿色6/10。可见任意颜色稳定抓起15/20（75%），其中颜色正确14/15（93.3%）。错色抓起并放碗1/20（ep19，green指令却放入red）；未见稳定抓起5/20（ep05、11、12、14、20）。正确颜色稳定抓起的14条全部最终留碗14/14。15次可见稳定抓起全部完成相应颜色的放碗15/15。

## 来源和判据

本轮为助手离线视觉复核，非新增操作者人工验收。编号01–20为计划trial编号，各独立dataset内部均为episode_index=0。

只读原始 `/data/work/so101-evidence/real-robot/smolvla-v2-random20-20261104/collection-package/` 和各 `eval-smolvla-v2-random20-t*-20261104` 数据集。未连接硬件、未训练、未改原始记录。分析产物位于 `/data/work/so101-evidence/real-robot/smolvla-v2-random20-20261104/visual-analysis/`；下文图像/JSON短文件名均相对该证据目录。任务颜色逐项读取plan.json；特别注意08和13的任务都是red，这两条红块入碗属于成功。

- 稳定抓起：可见方块脱离桌面并被夹爪持续带走/向碗运输。推、倾斜、翻转和短暂夹挤不计稳定抓起。未设置以毫米/毫秒计的自动阈值。
- 颜色正确率：在15条有明确稳定抓起的episode中，首次稳定抓起颜色与该episode指令一致。其余5条分母排除，不能把它们当作错色。
- 正确放碗：指令颜色的方块在尾部两帧均位于碗内，并有前段抓取/运输证据。错色入碗不算成功。
- “未见稳定抓起”不等于数学证明任何瞬时离桌均未发生。图像遮挡下的极短离桌无法排除；本报告不据此推断夹持力、精确抓取高度或接触机制。
- 首次尝试成功、精确重试次数、初始网格中心毫米误差、安全停止/人为终止原因未做定量判定，逐条JSON用null保留未知；短时长和正常回执不能证明正常自动结束或不存在人为操作。

## 失败过程与证据

05（red，22.00s）：约4s红块被夹爪碰歪/推移，5.25s仍在桌面，5.75–6.25s空爪到碗上方；后面重复接近红块，末帧两块都在桌面。11（green，28.70s）：约4.25–8.75s持续推转、倾斜绿块，9.25s绿块仍在桌面，10s空爪到碗上方；后续再次接近，最终未带走。12（green，28.75s）：先接近绿块，5.25s绿块仍在桌面，6s空爪到碗上方；后面反复接近，且有靠近红块的动作，最终两块都未入碗。14（red，28.70s）：多次夹挤/推动红块，但其仍留桌面；尾部红块在碗外，不能把末端在碗上方算作运输。20（green，28.75s）：多次接近绿块，10.25s绿块仍留桌面，约12–16s空爪到碗方向；尾部两块仍在桌面。对应`focus_05/11/12/14/20.jpg`及`grasp_dense_*.jpg`。

19（green，13.80s）：约4s夹红块，6s红块明确离桌随爪移动，8s已在碗内；绿色留桌。这是明确的错色抓取/放碗。08和13虽然同样红块入碗，指令为red，因此正确。对应`focus_19.jpg`、`focus_08.jpg`、`focus_13.jpg`。

06前段未完成抓取，后来约11–13s带绿块到碗；终局成功不表示首抓成功。01也有多次接近后才完成运输。因此本报告不给出未经逐帧标定的首抓率与重试次数。

## 执行、视频完整性和数值上下文

20份execution均complete=true；recording/status均complete、closed，accepted=written，dropped=0、errors=[]、pending_bytes=queue_items=0、close_timeout=false。40条侧面/腕部录像全部顺序解码通过，每条声明帧数等于实际可解码帧数。两相机各6969帧，共13938帧，单条10.30–28.75s。此检查证明保存的视频容器可完整解码，不证明曝光时间、采集过程没有重复图像或接触过程始终无遮挡。

原始plan.status及results.csv仍标not_run，CSV的20个人工评分字段未填写。这是采集模板未回填，与20份完成回执及实际视频相冲突；不能拿模板状态当“没有运行”，也不能把执行complete当物理任务成功。本分析保持原文件不动，独立输出视觉结果。

数值审计见[REPORT.md](/data/work/so101-evidence/real-robot/smolvla-v2-random20-20261104/numeric-analysis/REPORT.md)，同目录含`verification.json`、`supplement.json`：20/20 archive完整，6969帧、183请求、163边界；archive输出与数据集parquet逐元素相同，queue replay通过。实际183条任务文本和language tokens均解码符合计划；这排除了这批记录中的明显错传指令，不能证明模型理解/利用了语言。

输出19.940–19.976Hz，warm推理均值182.10ms、p95 191.01ms、max197.24ms，starvation/skipped均0。模型SHA256 `16d9116230bf5bb8eba4f6a9c9bbf635df9f3d93869b04da3f66252ce3e44b85`；runtime与generalization16一致。25次限幅发生01=3、05=5、06=1、11=10、12=6：既有成功条（01/06），也有失败条（05/11/12），14/20失败时则零限幅。只能描述共现，不能据此认定限幅、动作换块或抖动导致抓取失败。全部preflight通过，整体光照和相机对齐检查未见明显偏离；局部遮挡、阴影、摆放和物理接触误差仍不能排除。

## 解释边界

本批主要损失来自5条未形成稳定带物运输和1条错色。观察到正确颜色稳定抓起之后，14条都完成留碗；本样本不支持把“普遍运输中掉落/投放失败”列为主要失败类型。颜色判定的14/15是条件比例，不能替代端到端14/20。

历史generalization16为9/16（红7/8、绿2/8），本批14/20（红8/10、绿6/10），仅是不同布局、不同采集批次的描述性对照。随机20条并非所有格点组合穷举，每条单次，不能证明统计显著改善、泛化覆盖完整，也不能将两批直接合并成同分布成功率。无语言反事实、固定噪声或训练消融证据，不能把ep19归因为语言失效、颜色视觉失效或位置偏好中的某一项。
