v3 balanced112 最终 8400-step checkpoint 在本批 C2/C3 测试中退步，暂不替换 v2 full262 的 20000-step checkpoint。以下为保存视频的离线视觉复核，非新增人工验收；每版仅12条，不外推总体可靠率。

## 排查结果

- v3 12条共4243帧，archive与parquet动作逐元素一致，无丢帧/写入错误；原08采集完整不等于执行正常。
- 113次推理的实际语言token经本地解码全部符合颜色指令；模型hash与计划一致。不是只检查启动命令。
- 同一运行代码，20 Hz、horizon50、prefetch10、max_relative_target30；v3 warm推理均值约182 ms，队列饥饿0。无持续算力不足证据。
- 两版preflight全部通过，光照与对齐数值接近，未发现明显失控；不能排除局部阴影、摆放与接触差异。
- 初姿并非严格相同：v3相对v2 wrist_roll均值约+4.89、夹爪约−3.04（数据state标度，非确认物理度/mm）。v3前8条夹爪1.16–2.52，重启后续测9.18–12.24。后续对照必须固定夹爪开度和腕部初姿。
- 硬切chunk仍存在动作不连续：边界最大相邻目标差v2 39.698、v3 43.192；限幅日志每千输出帧约3.22 / 4.95。并非所有分位数均恶化，不能直接认定其导致选色错误。

## 解释边界与下一步建议

本批同时出现抓取失败和颜色执行错误。错误抓取有红指令抓绿，也有绿指令抓红，不支持简单解释为固定偏红；仅凭本批不能证明模型忽略语言或固定偏某格位。

v3同时改变了数据262→112、分层采样、归一化统计、训练步数20000→8400及warmup/decay。平均数据重复次数相近不等于优化步数或学习进度相等，因此不能把退步单独归因于“均衡数据策略”。

建议顺序（本次仅完成离线记录审计，未启动以下模型评估或训练）：

1. 保留v2 20k为当前对照。使用相同验证样本和共享噪声，在各模型自己的反归一化后比较v3早期checkpoint与最终checkpoint的逐关节原始尺度动作误差；不能直接比较两版归一化flow loss。
2. 在同一批真实观测、相同噪声下分别输入红/绿指令，比较v2/v3动作对指令的响应，并结合目标几何判断；动作差异本身不等于颜色语义正确。
3. 再决定训练消融：优先考虑保留全部合格数据、仅改变采样权重，固定统计量、训练步数和调度，以分离裁剪数据与均衡采样的影响。当前证据不足以直接启动下一版或承诺恢复成功率。
