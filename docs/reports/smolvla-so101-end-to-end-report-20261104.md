# SO101 红绿方块 SmolVLA：采集、训练与真机验证总结

更新：2026-11-04。目标是**一个模型按语言指令选择红块或绿块，抓起并放进纸碗**。本文汇总已执行工作，区分已验证结果、解释假设和待实施建议。全部成功率来自有限真机试次的视频离线复核，不代表全工作区可靠率；各批次独立列示，不拼成一个总成功率。

## 1. 当前判断

v2 full262 / 20k 是当前对照模型。它在已重点补采的 C2/C3 布局上有明显进展，但换位置组合后的颜色选择和抓取仍不可靠。v3 balanced112 / 8400 在同组回归上退步，未替换 v2。异步推理解决了同步推理阻塞控制线程的问题，却没有自动解决动作块交接跳变、目标选色和接触误差。

后续应保留合格示范的覆盖面，用同一物理布局下的双色指令配对数据减少位置与颜色的关联，并将位置组合留出用于测试。不能仅凭验证损失下降、动作更平滑或个别布局高成功率宣布优化完成。

|v2|262 / 75880|125 / 137|76 / 23145|44 / 32|

### 3.2 从局部缺口诊断扩展到三组位置对

v1 在 C2/C3 换位布局出现绿色任务失败，最初拟定36条局部补采。其他位置16条回归仅7/16成功，说明问题超出 C2/C3，最终采用72条扩展方案：B1/B2、C2/C3、D3/D4 三组位置对 × 红绿互换 × 两种指令 × 两种位置变体 × 三次独立重摆批次。

每批24条，双色分目录便于操作，但同批双色同属一个 split：前两批48条进入 train，第三批24条进入 validation。卡片顺序、命令顺序与 episode 映射绑定；非标准位置偏移/角度突出显示。正式偏移为 B01 中心/+3mm、B02 中心/−3mm、B03 中心/+2mm，两块共同沿纸面列号方向移动，行轴及角度保持0。原36条方案是历史草案，不与72条相加。

G19（B02-green ep6）错抓红色被排除，原始记录保留；补录 green ep0 共313帧。补录成功示范通过映射替换接受集中的对应逻辑条目；没有把失败源文件改成成功。v2 使用修正后的 split 与批准 receipt，具体映射见历史证据索引。补采得到的是指定位置对附近的示范，不能自动覆盖这些格位的所有交叉组合。

### 3.3 v3 均衡裁剪实验

v3 从已有合格数据筛选112条，绿红各56，旧数据64、新数据48，实际采样为新48/旧64各50%，各层内绿红各50%，每色 episode 均匀后再在 episode 内 frame 均匀，带放回采样。相比 v2 的全部262条，这同时改变了数据量、轨迹多样性、采样分布、归一化统计、训练步数及学习率日程。它是一个组合方案对照，不能单独估计“均衡采样”的效果。

经验：优先检查 `(目标颜色, 目标位置, 干扰块位置, 摆放变化, 来源批次)` 联合分布。只把红绿总条数调成一样，不能消除位置捷径；强行对称裁剪还可能丢掉有效的抓取和恢复轨迹。

## 4. 训练与模型选择

三版均从固定官方 base 开始微调，不把 v2/v3 误写为接着上一版继续训练。batch32、seed1000、AdamW 初始学习率1e-4，保留既定冻结策略。v1 虽配置关闭 AMP，实际保留官方 native BF16/F32 混合参数；v2/v3 在优化器创建前显式转全 FP32。这也是 v1→v2 对比中的变化因素。v1 在 antzb 等 RED ACT 完成后训练；v2、v3 实际在本机训练。v3 的证据目录包含 `matpool`，但云端租用准备并不等于云端正式训练。

|模型|训练步数|用途与结论|
|---|---:|---|
|v1|20000；另诊断15000 checkpoint|建立语言双色基线；局部换位、泛化和连续性问题明显|
|v2 full262|20000|增加48条训练/24条验证示范后形成当前对照；final20k 已严格重载和验收|
|v3 balanced112|8400|按近似数据重复次数配置；真机回归退步，保留作诊断对照|

训练验收包括数据/模型 SHA、实际 batch 双色采样、有限 loss/梯度、处理器统计、checkpoint 严格重载和完整验证集评估。不能只检查输出目录存在或日志打印了 started。部分早期准备文档停留在排队或 step34；完成状态以最终 verification/receipt 为准。

**验证损失的正确用法：** 同版固定数据和统计下可看学习曲线；不同版重算归一化统计后，native flow loss 数值不是相同尺度。v3 与 v2 应在同一验证观测、同一噪声条件下，将各自预测反归一化后比较原始 state/action 标度误差，并最终用真机选色和入碗评价。相近 epoch 数不等于相同优化步数、学习率阶段或学习量。

## 5. 从同步推理到可审计异步控制

初始离线 smoke：FP32 chunk 中位149.51ms，BF16 142.88ms；单次生成50动作虽有吞吐余量，同步换块仍阻塞约143–150ms，最长动作就绪间隔约191–198ms。平均19.xHz会掩盖块边界停顿，不能据此认定连续20Hz。

之后采用后台提前推理，按绝对控制 tick 对齐并裁去已经过期的新 chunk 前缀；episode/task reset 清空队列，旧 generation 的在途结果不能进入新任务。当前20Hz、50步、prefetch10 的运行中通常在还剩10步时请求，新结果安装时已过4tick、旧块还剩6步。计算跟上不意味着观测零延迟，亦不意味着新旧预测连续。

离线4/6tick融合降低了数值边界差，却出现较大局部轨迹偏离；后续受约束候选未通过预先冻结的保留条件，因此**没有部署融合策略**，当前仍为 hard。固定录制观测的重放没有跟随新动作变化的闭环反馈，不能替代真实接触和安全验证。

完整推理 archive 随后记录实际观测、语言tokens、noise、raw chunk、新旧future、安装tick及输出，补足了早期只靠 dataset 帧号近似推理输入的不足。固定输入/噪声的 v1 诊断显示语言有响应，但不同换位布局响应不一致；两个大交接在固定 noise 后仍有显著差异。因此既不能断言模型完全忽略语言，也不能把抖动全部归因于采样 noise。

测试入口进一步实现模型常驻：同一进程复用模型，每 case 重置状态并完成设备清理，避免每条重载。persistent collection 在条间等待 Enter；普通多 episode launcher 则自动回初姿、进入20秒 reset 后自动开始下一条，两者操作语义不可混用。

### 6.1 本次随机布局20条

本组为七个已用格位的42种有序双色组合中抽取20种，不是全桌面连续随机；目标绿红各10条，每组合没有重复。正确入碗14/20（70%），任意色稳定抓起15/20，首次稳定抓起颜色正确14/15（93.3%）；未抓起的5条不计为颜色正确。

- 唯一错色：trial19，G B3/R C3，绿指令抓红并放入碗。
- 未观察到稳定抓起：trial05（G D3/R B2，红）、11（G C3/R D4，绿）、12（G B3/R B1，绿）、14（G D3/R C2，红）、20（G C2/R D3，绿）。
- 目标格单独不能解释结果：绿B3在红D4时成功、红B1时抓取失败、红C3时错色；绿C2在红B3/D4/C3时成功，红D3时失败。每组合仅一次，提示关注联合布局，不证明因果。

20条回执正常，两路视频全解码通过；6969帧、183实际推理请求，输出archive与parquet逐元素一致。183条实际语言输入tokens全部符合计划。20次preflight通过，输出19.940–19.976Hz，warm推理均值182.10ms、p95 191.01ms，饥饿/跳tick均0。25次限幅集中于01/05/06/11/12；既有成功也有失败，不能简单把限幅等同失败原因。

相比此前新组合16条的9/16，本次14/20更高，但布局分布、重复次数不同，模型并未更新，不能称为算法提升。完整逐条表、视觉证据与数值审计见[随机20结果](../experiments/smolvla-v2-random20-results-20261104.md)。

### 6.2 本次自由摆放 ad-hoc

实际保存20条：绿色10:05:47目录5条、10:11:33目录5条，红色10:15:48目录10条。两个绿色目录都是有效保存数据，不能把第一目录当启动废片删去。

绿色自主正确入碗7/10（两目录分别3/5、4/5）；红色自主正确入碗3/10，另1/10人工协助后入碗。合计自主成功10/20，不能把物理末态入碗11/20当自主成功率。人工协助条是红色第2条（从0起 episode_index=1，分析ID R-01），约8–9秒人手进入工作区，用户已明确确认协助；保留在10次尝试分母中。最初交流曾误称为第1条，已依数据映射及用户再次确认更正。

本轮未冻结随机分布或精确格位，红绿各10条也并非同布局成对控制；因此红30%低于绿70%不能直接解释为颜色能力反转。同样，随机布局红80%与ad-hoc红30%的差距不能归因于训练变化——模型没有重新训练，摆放分布不同。

三次启动preflight均通过，遥测动作数分别2384/1794/4600，总计8778帧，与各目录保存帧数对应；所有episode有效输出约19.975–19.976Hz，starved/skipped均0，telemetry failed=null。第一绿色目录有1个stale result被丢弃，记录为reset隔离相关遥测，不能把它当作已发错误任务动作；没有持续控制供给不足的证据。本次ad-hoc审计未取得并验证完整推理archive，不能把random20的逐元素queue/token证明套用到本组。

绿色未入碗为G1-01/G1-02/G2-02；红色非协助失败为R-00/02/03/05/07/08（这些ID末尾为0起episode）。可见反复接近、抓空后继续向碗运行的现象，暂未看到错色块最终入碗。ad-hoc首个稳定抓起、精确重试次数未全部逐帧编码，保持未知，不能把“没有错色末态”说成选色100%。

### 6.3 优化效果的边界

v1→v2 同类 C2/C3 回归从9/12到11/12，绿色3/6到5/6，是支持保留v2的实测证据；但采集、日期、dtype与初姿等有差异，不是纯补采效果的受控因果估计。v2在新组合与自由摆放上的表现仍不稳定；C2/C3局部91.7%不能代表所有位置。v3本轮58.3%低于v2，但不能推导“均衡数据一定有害”。



判断口径：先确认稳定离桌夹持，再判首个稳定抓起颜色；最终指令色释放入碗才算任务成功。抓空不能算颜色正确，夹着正确块超时也不算入碗。若过程中先错色后再成功，应同时保留首抓错误与最终结果。视频抽帧可能漏掉短暂接触或掉落，疑难样本补时序，并将不确定性独立标识。

## 7. 已沉淀的 know-how

1. **数据比单纯延长训练更值得优先检查。** 使用相同布局分别演示红/绿指令；同时交换物块位置，避免指令和固定抓取点绑定。示范必须完整包含接近、夹起、搬运、释放、撤离。
2. **数据质量和完整性是两件事。** 完整可解码的 episode 可以是错色、空抓或安全异常；需要结构校验加全流程视觉判断。失败 rollout 用作诊断，不直接混入专家示范。
3. **留出要按来源批次并同时留出双色。** 不通过改目录名制造独立性；开发中看过、用于决定补采的位置测试不再是全新测试集。
4. **对比要固定输入链路。** 权重、processor统计、camera映射、任务文本、初姿、夹爪开度、灯光、相机位置和 runtime 参数均应记录。preflight 通过不能排除局部阴影、色差或几毫米摆放差异。
5. **时间序列要看尾部和换块。** 平均Hz、单次推理均值不足以定位抖动；同时查饥饿、跳tick、观测年龄、边界差和限幅。CPU限幅前目标不等于实际串口指令，更不等于真实机械位移。旧报告中标作度的数值，应结合标定配置确认单位，不盲目作物理角度比较。
6. **语言对照必须固定noise和观测。** 只换指令，检查其它输入逐元素相同；语言造成动作变化不代表目标变化正确。当前固定两条TASK，改写文本需独立实验。
7. **机械退出属于测试结果的一部分。** 持物超时后曾发生夹爪ID6关闭力矩时Overload，保留异常回执；用户断电取块复位后才续测。采集完整性恢复不能将异常执行改写为正常，也不能以增加重试/关闭保护掩盖问题。
8. **减少人工等待而不降低可追溯性。** 一页20条布局卡、颜色分批、模型常驻、预检自动化、每条独立dataset和receipt；结果统一回收分析。图片先查尺寸，默认≤1600px预览；侧面每ep首中尾各两帧、10ep拼图，疑难追加局部时序。
9. **结果分母必须明确。** 目标色入碗/全部尝试、正确色抓起/全部尝试、首抓颜色正确/有稳定抓起分别报告。自主选位置的ad-hoc与冻结随机布局属于不同抽样机制，不合并估计全局成功率。
10. **产物应能离线复现。** 锁包版本、固定官方revision、保留split/源映射/训练统计/模型SHA，上传模型连同processors和配置；Hub只发布核验过的接受集，原始证据留本地。

## 8. 后续优化顺序（建议，尚未执行）

先保留 v2 final20k 的权重与 hard runtime 作为对照，避免数据、控制、相机和语言同时改动。把新测试失败划分为错色、抓取接触失败、搬运/释放失败与运行异常，再映射到训练覆盖。复用本轮真实观测/实际noise做小规模语言交换实验，核验问题是否集中于某些目标/干扰位置组合；离线动作差仅作诊断。

本次随机测试5条未稳定抓起，却多次出现空爪向碗移动，提示补采应同时覆盖接触对齐和失败后恢复；仅增加颜色词或仅录成功后的运输段，未必覆盖主要误差。恢复示范若另行采集，应明确起始失败状态、正确重抓和终止条件，不能把现有失败rollout自动当成合格示范。

下一版优先保留全部合格数据，用采样权重而非大幅裁剪实现更合理覆盖。若要验证采样方案本身，固定数据集合、统计、总步数和调度，只改变采样；若补采，针对本轮失败组合做同布局双指令配对，并留出独立重摆批次。新数据、优化器配置或控制改变应分别设对照，避免重演 v3 多因素同时变化的归因困难。

在同一固定回归集上比较新模型，再用未用于调参的布局组合验证泛化。重复次数、初姿/开度和终止规则预先固定，失败及异常不替换删除。连续性改进单独作为控制实验，只有离线约束通过后才安排监督真机测试。本报告未启动新训练、补采或硬件动作。
